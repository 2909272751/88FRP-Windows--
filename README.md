# 88FRP Windows 原生客户端

一个面向 Windows 的 88FRP 桌面客户端，提供原生窗口、托盘后台运行、开机自启动、远程配置同步、隧道选择和日志查看。

## 主要功能

- 原生 Windows 桌面界面，双击 `88FRP.exe` 即可使用
- 3.2.3 统一桌面和 Web 的字体、主操作及卡片层级，修复折叠、输入与刷新记忆；默认展示隧道，配置同步按需展开
- 关闭窗口后保持托盘后台运行
- 首次启动引导设置开机自启动
- SYSTEM 开机后台任务 + 用户登录托盘任务，无需登录即可恢复隧道与域名同步
- 后台核心、主隧道和访问中心均有自动守护，网络抖动或进程异常后会持续重连
- 自动同步最低间隔为 5 分钟，遇到超时或限流时自动退避，避免频繁请求
- 域名绑定在原生桌面和 Web 控制台均可配置，所有隧道（含未启用）共用域名、按端口访问
- 默认每 15 秒检查节点 IP，可设为 5–3600 秒；IP 不变不访问 Cloudflare，变化后才核对解析，失败退避重试
- 支持同步 88FRP 远程配置
- 桌面端与 Web 控制台均可连接 88FRP 账号并显示隧道备注名称
- 可选择保存加密密码，在登录失效时自动重新登录
- 现代化响应式 Web 控制台，支持手机、平板、桌面及明暗主题
- 支持只运行勾选的隧道
- 同步后保留已保存的隧道选择，新隧道默认关闭
- 按 88FRP 备注或隧道名称开头自动分组，支持整组启用/停用和手动覆盖分组
- 配置编辑、实例启动/停止/重启、运行日志查看
- 运行日志自动轮换，单份最多约 5 MB，并保留最近两份历史日志
- 高 DPI 适配，支持高分辨率屏幕
- 独立访问中心：用固定地址汇总已同步的隧道名称、访问链接与连接端点

## 下载使用

请在 GitHub Release 中下载：

```text
88FRP-Windows-Setup-3.2.3.exe
```

双击安装器并按向导完成安装即可。建议使用默认安装目录；也可以安装到固定目录，例如 `D:\88FRP\`。

覆盖升级也会显示欢迎、目录选择、快捷方式与自启动选项、安装确认和完成页。升级请直接覆盖安装，不要先卸载；安装前自动备份并保留原数据目录。也提供 `88FRP-Windows-3.2.3.zip` 便携包及兼容旧下载入口的 `88FRP-Windows.zip`。

安装后从开始菜单或桌面快捷方式打开 `88FRP`。不要单独打开 `88frp-web.exe`，它是隐藏运行的后台核心。

## 88FRP 账号与备注名称

在桌面端或 Web 控制台点击“连接 88FRP”，输入 88FRP 用户名和密码即可。

- 连接完成后会获取已有隧道的官方备注名称
- 同步配置发生变化时自动更新备注名称
- Web 隧道列表优先显示备注名称，并保留 FRPC 标识和端口信息
- 默认使用 Windows DPAPI 加密保存密码；取消勾选后，只保存登录令牌，不会自动重新登录

## 隧道选择逻辑

客户端会保存远程同步得到的完整配置，但实际运行时只生成包含已勾选隧道的运行配置。

- 完整配置：`frpc.toml`
- 隧道选择：`selection.json`
- 手动分组覆盖：`tunnel-groups.json`
- 实际运行配置：`runtime-frpc.toml`

同步远程配置后：

- 已存在隧道保留原来的启用/禁用状态
- 新出现的隧道默认关闭
- 未勾选隧道保留在配置中，但不会启动
- 名称含有 `-`、`_`、空格、`/`、`:` 等分隔符时，分隔符前内容会作为自动分组；没有分隔符时，会合并名称开头相同的隧道
- 例如“公司电脑”和“公司 alist”会自动归入“公司”；在隧道列表的“分组”输入框填写内容后，会优先使用手动分组，并在后续同步后保留

## 独立访问中心

桌面端左侧有“配置访问中心”。它适合把自己的 FRP 服务器作为一个固定入口使用：

1. 填写该 FRP 服务器地址、服务端口、分配给访问中心的公网端口和 Token。
2. 访问中心始终以公开只读模式启动，不设访问密码。
3. 客户端会在本机 `127.0.0.1:8802` 启动只读页面，并用一条独立 FRP 连接映射到固定公网地址。

访问中心会实时读取现有实例的同步配置、已保存的 88FRP 备注名称和启用状态；它不会修改原来的 88FRP 配置、隧道选择或运行进程。

- 所有 TCP 隧道默认生成可直接打开的 HTTP 链接
- UDP、STCP、SUDP、XTCP 会按实际协议展示，不能直接打开的不会伪造网页链接
- 访问链接本身可直接点击，在浏览器新标签页打开
- 按同步备注或隧道名称开头分组展示，每个分类可折叠；折叠状态会保存在当前浏览器
- 访问中心允许查看、复制和打开链接，但不会允许从公网修改链接设置
- FRP Token 使用本机 DPAPI 加密保存，不会从状态接口或页面返回
- 访问中心内置自定义服务器真实通道测速：默认 10 秒，显示延迟、当前/平均/峰值下载速度与已传输数据；测速不使用 88FRP 官方线路，不新增公网端口

任何知道固定地址的人都能看到隧道名称和访问链接，适合可信网络或不敏感的服务。访问中心通过 HTTP 提供时，建议仅在可信网络使用；要获得完整的传输抗篡改能力，需要让该入口具备可信 HTTPS。

## 控制台安全登录

88FRP 控制台的管理员账号与 88FRP 官方账号相互独立。首次在 Windows 客户端打开后，在“全局设置 → 控制台安全”设置管理员账号和密码；密码不会以明文保存。

- 普通登录的有效期为 24 小时；勾选“记住此设备”后，会话会持续有效，直到主动退出、在 Windows 客户端撤销会话、修改密码或清理浏览器数据。
- 密码校验采用 PBKDF2 派生、一次性挑战响应和 HTTP-only 会话 Cookie；本机保存的校验信息使用本机 DPAPI 保护。
- 为避免在不安全网络中传输登录凭据，远程浏览器登录需要可信 HTTPS；`127.0.0.1` 本机访问可正常登录。独立访问中心维持无密码只读，不受此设置影响。

## 自启动原理

安装时可选择开机自启，之后也可在原生客户端“设置 → 后台运行”中开关（需要管理员权限）。

- `88FRP Backend`：SYSTEM 身份，开机后延迟 45 秒运行隐藏后台，不需要登录；启动失败后每分钟重试。
- `88FRP Desktop`：当前用户登录后显示托盘入口，连接已经运行的后台。
- 旧登录任务及注册表启动项会清理，不再叠加启动。

安装器保留原来的数据目录，路径记在安装目录的 `machine-config.json`。旧账号、控制台验证信息、访问中心和 Cloudflare 的加密凭据会在安装时迁移为本机 DPAPI，原密文备份保存在数据目录的 `credential-backups`；目录权限限于所属用户、SYSTEM 和管理员。若使用其他 Windows 账号安装而无法解密旧凭据，安装会明确提示失败并保留数据。

## 域名绑定

在“域名绑定”页授权 Cloudflare Token，开启“启用域名绑定”，并在负责维护 DNS 的一台设备上打开“由本机修改解析”。其他设备保持只读。

- “自动跟随节点 IP”默认每 15 秒检查，可在桌面与 Web 域名页调整为 5–3600 秒；IP 不变不请求 Cloudflare，IP 或绑定目标变化后才核对并按需写入。首次启动与手动同步仍核对一次。
- IP 检查频率与 DNS 缓存 TTL 独立；缓存过期前部分设备可能继续使用旧 IP。
- 访问中心并列展示域名链接与节点直连，各自支持复制和打开；保留自定义链接，未启用隧道仍可查看和复制地址。
- 只读模式下，预览、授权验证及同步均不发送 DNS 写请求。
- 所有隧道共用一条灰云 A 记录，未启用隧道仍显示访问地址；它们需要在面板启用后才可连接。
- 预览只读取 Cloudflare；同步不会覆盖手工 A / AAAA / CNAME。TXT 可与 A 记录共存。
- 删除部分隧道保留共享记录；不再需要的旧记录只在“本机账本 + 精确托管备注”均匹配时清理。
- 界面显示自动检查状态、最后检查和错误信息；网络失败、限流和授权失效均有提示与后台重试。

## 卸载

卸载会先停止后台和受管隧道，并清理两个计划任务和历史启动项。默认保留数据（静默卸载也保留）；交互卸载时明确选择“否”才删除原用户目录中的数据。升级请直接覆盖安装，不要先卸载。

## 常见问题

### 为什么同步配置提示 500？

这通常表示远程配置接口返回错误。常见原因：

- 密钥不正确
- 88FRP 平台接口临时异常
- 当前账号没有返回有效配置

请检查密钥后再同步。

### 为什么不建议单独打开 88frp-web.exe？

`88frp-web.exe` 是后台核心，不是用户入口。普通用户应该打开 `88FRP.exe`。

### 这是 Windows Service 吗？

后台使用 SYSTEM 开机计划任务，无需用户登录；用户登录后单独启动原生托盘客户端。没有额外注册 Windows Service。
