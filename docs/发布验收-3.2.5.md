# 3.2.5 访问中心链接验收

日期：2026-10-17。

- 原因：地址行错误地把本机隧道 enabled 作为生成超链接和启用打开按钮的前提，其他设备使用的隧道因此只能复制。
- 修复：地址可点击能力只由链接类型和有效地址决定；域名、自定义地址与节点直连统一处理，未启用状态保留。UDP 与纯地址模式不生成网页链接。
- 重复覆盖升级实测发现：旧任务被强制结束时可能打断状态文件写入。改为先禁用任务、后台正常退出；旧文件短暂不完整时有界重试，持续损坏则中止。JSON 保存使用同目录临时文件原子替换并按文件串行，写入失败保留完整原文件。
- 自动测试：88 项，87 通过，1 项按平台预期跳过，0 失败。新增行为回归覆盖未启用域名/直连/自定义地址的真实锚点和打开按钮、UDP、纯地址、启用数量，以及保存中断、读取中途状态与保存顺序。
- 旧服务升级保护继续沿用 3.2.4 机制。
- 实际覆盖升级：公司电脑从 3.2.4 升级成功，安装器返回 0，7 个已安装文件哈希与交付包一致。原目录及所有者保持不变，配置/选择/分组/标签哈希和域名选项不变，20 条隧道、10 条启用保留。
- 运行验收：实例、访问中心、SYSTEM 开机任务和用户登录任务均运行；后台一份，旧服务及旧服务程序未复现，备份完整保留。
- 公网验收：真实访问中心显示 3.2.5、已连接、20 条隧道、19 个可打开地址。未启用隧道显示真实域名和节点超链接及可用打开按钮，UDP 仍不可网页打开。
- 域名自动跟随：指定设备启用写入、自动跟随及 5 秒检查，另一设备只读；实际 DNS 与当前节点一致，升级后设置保留。检查周期不等于 DNS 缓存生效时间。
