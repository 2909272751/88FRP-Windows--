## 本轮修复摘要

- 修复 `gateway.html` 漏加载 `api.js` 导致整页 `API is not defined`、所有入口失效。
- 首屏增加本地缓存和稳定加载骨架；生产接口慢时不再白屏或误报“后台未连接”。
- 服务列表分“已发布 / 未发布”；停用服务移除复制、打开入口，消除死链。
- 运行状态页移除 Caddy、frpc、PID、原始 JSON 等工程词，并收敛旧运行时错误文案。
- 页面标题统一 26px、说明 12px、正文 13px、卡片标题 16px；1000 宽度改单列。
- 修复 Windows 配置文件读写竞争：同一文件的读取和原子替换改为串行队列，消除 `EPERM` 重命名失败。
- 原生客户端只把当前页放入可视树；管理抽屉按需加入/移除；概览空状态不再被无障碍树误读。

## 部署状态与注意事项

- 用户级程序：`C:\Users\29092\AppData\Local\Programs\88FRP\88FRP.exe` 已更新为 3.3.1；桌面和开始菜单快捷方式均指向该目录，无需 UAC 即可使用。
- 生产静态资源：`%LOCALAPPDATA%\88frp-node\runtime\public` 已同步为最终版本，当前 8801 后台立即提供新界面。
- SYSTEM 后台：`88FRP Backend` 仍运行 `C:\Program Files\88FRP` 下的旧 `88frp-web.exe`。因此新后台的接口缓存性能优化尚未在该 SYSTEM 进程内生效，需要下一次管理员覆盖升级或后台重启后才能完全上线；本次首屏指标通过前端骨架/缓存达标。
- 旧安装器的 `88FRP Desktop` 计划任务仍指向 `C:\Program Files\88FRP\88FRP.exe`，当前用户权限无法改写；桌面与开始菜单快捷方式已指向新版用户级客户端。
- 证据目录中的截图来自真实生产 8801 页面；原生截图受当前断开的远程桌面会话限制无法抓取像素，结构验收以 Windows UIA 树为准。
