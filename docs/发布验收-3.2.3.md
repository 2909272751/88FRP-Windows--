# 3.2.3 访问中心域名与按需 DNS 更新验收

日期：2026-10-17。

## 行为

- 访问中心从当前实例的本地域名绑定设置生成域名链接，与节点直连并列；每个地址单独复制和打开，域名参与搜索。自定义链接继续保留。
- 未启用隧道仍展示和允许复制地址；UDP 只提供连接端点，Visitor 不伪造网页。公开列表不查询 Cloudflare，也不返回凭据。
- 自动跟随先检查节点 IP；首次、IP 或绑定目标变化、手动同步才核对 Cloudflare。IP 不变不循环请求 Cloudflare，仅改变检查间隔也不触发无关核对。
- IP 检查默认 15 秒，桌面与 Web 可设为 5–3600 秒；暂停、只读及每次写入前重查设置仍生效。失败至少等待 30 秒，并逐步退避到 15 分钟。
- IP 检查周期与 DNS 缓存 TTL 独立，部分客户端仍需等待缓存过期。

## 验证

| 项目 | 结果 |
|---|---|
| 自动测试 | 78 项：77 通过，1 项按预期跳过，0 失败 |
| 不变 IP | 首次核对完成后，多轮检查不增加 Cloudflare 请求；模拟运行节点 IP 变化后按需更新一次 |
| 间隔与暂停 | 默认值、5 秒边界、非法值、实时保存、失败退避、暂停及手动同步已验证 |
| 访问中心 | 域名与原节点链接并列、复制内容正确、按域名搜索命中、未启用状态与原自定义地址保留 |
| 双端设置 | Web 保存 5 秒并刷新保留；原生窗口读取相同值，改为 10 秒后 Web 能读取 |
| 响应式 | 390 像素手机单列，无页面横向溢出；桌面双列地址卡片清晰 |
| 数据保护 | 已安装 3.2.3；与自动备份对比，账号内容、三项域名开关、记录账本、隧道选择、分组和端口保持一致；新增默认检查间隔 15 秒 |

访问中心页面检查使用独立测试数据，不新增公网入口、不改真实 DNS。部署到其他电脑的访问中心需要该电脑升级到本版本，并有对应实例的域名绑定配置。
