# 88FRP 3.4 可交付 UI 评分表

评分对象：公开导航页、统一入口控制台、Windows 桌面客户端。

规则：每项 10 分，总分 100 分。只有真实页面、真实客户端和实际操作均通过才计满分；截图、自动化检查、UIA 文本与测试结果作为证据。

## 目标

1. 普通用户打开后先看到“这台设备能做什么”，而不是工程状态、配置项和宣传语。
2. 一台设备只有一个清晰入口；服务、远程访问、设置分层明确。
3. 首屏不重复展示同一地址，不用四宫格后台指标充当内容。
4. 主界面不出现域名同步、DNS、证书、端口规则等工程细节；这些统一放入设置中的可展开区域。
5. 所有操作有即时反馈，加载不白屏，失败可恢复，窄屏不裁切。
6. Web 与 Windows 客户端使用同一套信息架构、术语和视觉层级。

## 主要扣分原因

- 首页用 238px 大横幅承载设备名和 URL，下方又出现统计四宫格和“设置与检查”，层级像后台看板。
- “域名与证书”“运行状态”占两个一级入口，日常使用几乎不需要。
- 服务卡同时露出复制、打开、编辑、删除，管理动作压过“打开”。
- 公开导航页首屏有过大的“服务入口”标题和说明，每次访问都要先读宣传语。
- 桌面“全局设置”仍塞有历史实例、旧版访问中心、本机服务端口、软件更新、高级诊断等旧产品残留。
- 两端目前是五页结构，和“一台设备、一个入口、服务优先”的使用场景不一致。
