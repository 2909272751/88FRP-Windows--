## 结论

3.7.0 达到可交付状态。网页管理页、公开导航页和 Windows 原生客户端使用同一套设备、服务、域名和三线路语义；设置页不再被日志和完整健康探测拖慢，核心公网链路已在真实生产进程上完成闭环验证。

## 已知交付边界

- 当前按用户要求采用“不重装、不触发 UAC”的用户目录覆盖。用户登录启动项会优先启动 3.7.0 用户级核心并接管旧后台。
- `C:\Program Files\88FRP` 下的旧 3.3.0 与 SYSTEM 计划任务仍存在；整机重启后、用户登录前，旧任务可能先占用后台。要彻底消除这段登录前窗口，需要一次有人确认 UAC 的安装器覆盖，或由管理员修改 `88FRP Backend` 计划任务路径。该边界不影响当前已登录生产实例和公网三线路验证。
